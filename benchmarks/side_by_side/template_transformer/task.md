# 任务：把组会初稿套用到课题组模板

材料：
- `draft_transformer_talk.pptx`：一位同学的组会初稿（4:3，格式较乱：手动字体、红色正文、文本框假标题、原生图表、过长的页面）。
- `group_template.potx`：课题组统一模板（16:9，版式名为中文：封面 / 正文-单栏 / 章节过渡 / 双栏对比 / 仅标题 / 图片+说明 / 空白页）。
- `attention_is_all_you_need.pdf`：初稿所讲的论文，用于核对。

要求：
1. 每一页都必须使用模板的母版与版式，标题进入标题占位符，字体与配色服从模板主题，每页有页码。
2. 不得删改初稿中的文字、数字、图片与备注；放不下的页面可以拆页，但须记录。
3. 原生图表若无法保持可编辑，须说明。
4. 给出适配前、适配后的逐页格式偏差记录，以及原页到模板版式的映射。
5. 导出 PDF 与逐页 PNG 预览；初稿中的数字须与论文核对，若有不一致请报告（不要擅自修改）。
6. 交付 `result.json`，包含 `case.json` 中 output_contract 的全部字段。
