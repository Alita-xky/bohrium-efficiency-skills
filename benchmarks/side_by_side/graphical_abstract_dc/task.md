# 任务：为论文制作单页图形摘要（Graphical Abstract）

材料：`1607.07244.pdf`（Marcou et al., A model for the integration of conflicting exogenous and endogenous signals by dendritic cells）。

要求：
1. 按"研究问题 → 方法 → 核心结果 → 结论"四部分组织单页图形摘要，标题用中文，实体名（LPS、TNFα、IL-10、CD86 等）保留论文原文写法。
2. 核心结果中至少给出论文报告的两个定量结果（含单位），数值必须能在论文中找到。
3. 区分促炎与抗炎信号（颜色或箭头类型），并配图例。
4. 交付可编辑 SVG 源文件，以及 PDF 和 PNG（宽度 ≥ 1600 px）导出件。
5. 在 result.json 中给出四部分与论文段落的对应关系、每个关键元素的来源定位、导出检查和不确定性。
